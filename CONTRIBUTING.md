# Contributing to HEFIN

HEFIN handles healthcare-related information, so changes should favor safety, traceability, and conservative behavior.

## Guidelines

- Keep responses educational and avoid introducing autonomous diagnosis or prescription behavior.
- Add tests for safety gates, routing, retrieval, and API behavior when changing them.
- Never commit API keys, database credentials, JWT secrets, or private documents.
- Document changes to model providers, retrieval behavior, prompts, or infrastructure.

## Pull requests

Explain the problem, implementation, safety implications, and validation performed. Keep changes focused so they can be reviewed and reverted independently.
